# Graham Bonomo-Jackson

Engineer with 20+ years building software and hardware systems, including 11 years in healthcare. I work with Python, PyTorch and FPGA-based real-time systems, with a focus on reproducible ML experiments, uncertainty and model behaviour. I’m interested in research engineering and ML systems roles.

At work, I build dynamical-systems and manifold-trajectory analyses for operational data. My independent research explores whether model behaviour changes transfer beyond the examples used to produce them.

## Selected projects

- **[EXPCON](https://github.com/Gramathon/expcon)** — Python CLI for defining experiments, checking declared inputs, preserving execution evidence and evaluating frozen acceptance rules. Its CPU validation study includes trained and zero-epoch cases, evidence verification, and an independent check that recomputes metrics from saved model weights.
- **[ERATO](https://github.com/Gramathon/ERATO)** — research framework for tracking behavioural changes across post-training checkpoints. Current work tests whether preference shifts transfer to held-out prompts or remain specific to training examples. Representation-level analysis is planned.
- **[Bayzflow](https://github.com/Gramathon/bayzflow)** — PyTorch experiments with Bayesian uncertainty and neural observability.
- **Medical imaging** — independent DINOv2-based work and participation in the RSNA Knee competition.

I’m interested in research engineering and ML systems work where careful experiments and dependable software help answer questions about model behaviour.
