# Graham Bonomo-Jackson

I’m an engineer and independent ML researcher. I’ve spent more than 20 years
building software and hardware systems, including 11 years in healthcare. My
background is in electronic engineering, Python, PyTorch, FPGA-based real-time
computation, and the practical work of making hardware and software fit
together.

At work, I build dynamical-systems and manifold-trajectory analyses for
operational data. In my own research, I’m interested in uncertainty,
generalisation, and whether changes in a model’s behaviour hold up beyond the
examples used to produce them.

## Selected projects

- **[EXPCON](https://github.com/Gramathon/expcon)** — Python tooling for defining
  experiments, checking declared inputs, preserving execution evidence, and
  keeping execution status separate from scientific conclusions. It includes a
  small reproducible CPU study. It is research infrastructure, not a distributed
  training system or GPU optimiser.
- **[ERATO](https://github.com/Gramathon/ERATO)** — work on tracking behavioural
  changes across post-training checkpoints. I’m studying whether preference
  shifts carry over to held-out prompts or stay specific to the examples used
  during training. Representation-level analysis is planned work.
- **[Bayzflow](https://github.com/Gramathon/bayzflow)** — experiments with
  Bayesian uncertainty and neural observability in PyTorch models.
- **Medical imaging** — independent DINOv2-based work and participation in the
  RSNA Knee competition.

I’m most interested in research engineering and ML systems work where careful
experiments and dependable software help answer questions about model behaviour.
